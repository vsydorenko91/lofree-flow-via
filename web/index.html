Lofree Flow VIA Flasher

Install VIA support on the Lofree Flow84, or go back to the stock firmware. Runs entirely in your browser over USB (WebHID).

This browser cannot talk to the keyboard. Open this page in Chrome, Edge, Brave or Opera on a desktop.
Before you start
  • Use a USB-C cable, with the keyboard's switch on USB (not Bluetooth).
  • Flashing erases the saved profile (remaps, macros, lighting). Export your VIA layout first.
  • Do not unplug during the upload (about a minute). If it is interrupted, the keyboard stays in its bootloader and you can simply run the flash again.
  • This firmware is for the Lofree Flow84 only (84 keys). Do not flash it to a Flow100 or any other keyboard.
  • This is unofficial, third-party firmware, tested on one Flow84. You flash at your own risk.

Open usevia.app, go to Settings, turn on Show Design tab,

Stuck in the bootloader or the keyboard does not enumerate? Run the flash again; the bootloader accepts a new upload at any time. See docs/RECOVERY.md in the project repository.
